# EEE 598 Assignment 2 report (CVPR 2026 template)

Upload this folder (or `EEE598_HW2_report_overleaf.zip`) to Overleaf: **New Project → Upload Project**.
Compiler: pdfLaTeX. Main file: `main.tex`.

Before submitting, fix the red `[TODO: ...]` marks:
1. Your last name in `\author{...}` (top of `main.tex`).
2. Classmate help in the Acknowledgements.

The layout is the CVPR **review** style (line numbers, header), with the author name shown.
For the clean camera-ready look, change `\usepackage[review]{cvpr}` to `\usepackage{cvpr}`.

`make_figures.py` redraws the charts in `figs/` from the measured numbers.
